## Что нового в index.html

1. **Конструктор напитка** (аналог «коробки моти» у Моти, но свой):
   основа → объём → молоко → сироп → добавка, цена пересчитывается мгновенно,
   стакан наливается на глазах, готовый напиток падает в корзину со своим названием
   на языке интерфейса. Это второй вау-экран в дополнение к анимации «телефон → чашка».
2. **Комплект установки на телефон**: svg-значок, apple-touch-icon, icon-192/512, manifest.
3. **OG-блок расширен**: описание, `og:locale` + 4 альтернативных, `og:site_name`.
4. Немецкий регистр существительных в названии напитка учтён.
